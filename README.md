Student CRUD Backend

A simple backend application for performing CRUD operations on student records using Java and Spring Boot.

Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

Features
- Add new student
- Get all students
- Update student details
- Delete student

API Endpoints

1. Get All Students
GET /students

2. Add Student
POST /student

3. Update Student
PUT /students/rollno

4. Delete Student
DELETE /students/rollno

5. Database Configuration

Update `application.properties` with your MySQL credentials
